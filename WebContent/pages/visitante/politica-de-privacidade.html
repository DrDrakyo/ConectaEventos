Política de Privacidade

Última atualização: julho de 2026

Neste documento

1. Dados coletados 2. Uso dos dados 3. Compartilhamento de informações 4. Segurança dos dados 5. Direitos do usuário

1. Dados coletados

Coletamos os dados fornecidos no cadastro de Contratantes (nome, CPF/CNPJ, e-mail, telefone, endereço, cidade) e de Prestadores (nome, e-mail, telefone, nome fantasia, categoria, descrição, localização, contatos, disponibilidade), além das informações registradas em portfólios, contratações e avaliações.

2. Uso dos dados

Os dados cadastrais são utilizados para viabilizar o funcionamento da plataforma: exibição de perfis públicos, busca de prestadores, registro de contratações e cálculo de estatísticas administrativas, como categorias mais procuradas e volume de contratações.

3. Compartilhamento de informações

As informações de perfil de Prestadores (categoria, descrição, localização, portfólio e avaliações) são públicas por natureza da plataforma. Dados de contato de Contratantes são compartilhados com o Prestador apenas no contexto de uma contratação solicitada.

4. Segurança dos dados

Adotamos medidas para proteger os dados armazenados, incluindo controle de acesso por login e senha para Contratantes, Prestadores e Administrador.

5. Direitos do usuário

O usuário pode, a qualquer momento, atualizar seus dados cadastrais pela tela de Editar Perfil ou solicitar a desativação de sua conta pelas Configurações da Conta.
