# assets/img

Esta pasta foi criada para seguir o padrão de arquitetura do projeto
(assets/css, assets/js, assets/img, assets/icons).

No momento da reorganização, o projeto **Conecta Eventos** não utiliza
nenhum arquivo de imagem (.png, .jpg, .svg externo, etc.) — todos os
ícones da interface são SVGs embutidos diretamente no HTML de cada
página (ex.: ícone de busca, menu, marca "Conecta Eventos").

Por isso esta pasta está vazia, mas pronta para receber futuras imagens
do projeto (fotos de perfil, banners, ilustrações etc.) sem exigir nova
reorganização de estrutura.
