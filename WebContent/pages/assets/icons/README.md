# assets/icons

Esta pasta foi criada para seguir o padrão de arquitetura do projeto
(assets/css, assets/js, assets/img, assets/icons).

No momento da reorganização, todos os ícones do **Conecta Eventos**
(busca, menu hambúrguer, marca, setas, etc.) são SVGs embutidos
diretamente no markup HTML de cada página — não existem arquivos de
ícone isolados (.svg, .ico) no projeto original.

Por isso esta pasta está vazia, mas pronta para receber futuros
arquivos de ícone (ex.: favicon.ico, sprite de ícones .svg) sem exigir
nova reorganização de estrutura.
